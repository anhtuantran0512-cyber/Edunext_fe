# Edunext_fe
Bản free có giới hạn , script sẽ ngững hỗ trợ ngay sau khi api đạt giới hạn billing ( chi phí ) , có thể hỗ trợ chi phí trong gui 
- Mỗi 1 tick like thả biểu cảm script sẽ giảm đi thời gian cooldown và tăng thời gian sử dụng lên 5% cho mỗi emoji
- Cho mỗi share sẽ là 10% ( hệ thống tự ghi nhân và cập nhật )
- Tổng % dung lượng api sẽ là 100% chia cho toàn bộ người sử dụng :
+ nếu 1 người sử dụng hết 100% thì sẽ hết và chờ cooldown 
+ nên cài api để đảm bảo chất lượng , 15 api free ko đủ cho nhiều người 
+ Script có đuôi console_ dán : dùng đẻ dán vào console thay vì tampermonkey 
+ Người dùng sử dụng tampermonkey thì lấy bản có đuôi _freetrial ( nhớ bật developer mode , chế độ nhà phát triển bên ) script extension
